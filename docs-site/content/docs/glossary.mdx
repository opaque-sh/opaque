---
title: Glossary
description: Short definitions of terms used in these docs.
---

**Anonymity set.** The group of notes an observer cannot tell apart from yours. Bigger is better.

**Asset id.** A number stored inside every note's commitment. Always 1 ($OPA) for now.

**Backing.** The $OPA the pool holds for all $OPA notes.

**Commitment.** The hash of a note, stored as a leaf in the tree.

**Donation.** $OPA added to the backing without minting shares. It raises the value of every share.

**Exit.** Taking value out of the pool to a public address.

**Exit target.** A contract that receives an exit and acts on it. Planned.

**Guardian.** The only address that can pause new shrouds.

**Harvester.** The contract that collects $OPA's trade fees on Pons, pays the team its share and buys $OPA for the pool. Written, not audited or deployed.

**Note.** A private record of value, owned through a secret key.

**Nullifier.** A value revealed when a note is spent. A repeat is rejected.

**Pons.** The launchpad where $OPA is launched.

**Proof.** A zero-knowledge proof that a transaction is valid without revealing the notes.

**Root.** A fingerprint of the note tree at one moment.

**Shares.** The unit of $OPA notes. Their value rises as donations arrive.

**Shroud.** Deposit into the pool and receive a note.

**Stub.** The part of a note computed from the owner key, a random value and a blinding value. The pool completes it with the asset and amount.
